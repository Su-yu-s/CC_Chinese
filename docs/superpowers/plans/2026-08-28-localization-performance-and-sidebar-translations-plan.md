# 汉化提速与侧栏翻译实施计划

1. 在 `core/patch_chunks.py` 增加确定性补丁签名、assets 指纹、原子状态读写和缓存判定。
2. 将 chunk 发现拆成精确、稳定前缀、有界入口兜底三层，并在兜底检查时排除注入块。

4. 在恢复流程中删除 chunk 状态，避免恢复后错误跳过。
5. 修复五项菜单标签的静态映射与旧译名规范化，删除 `项目 -> Projects` 冲突；保留路径和用户文本保护。
6. 增加翻译、前缀发现、缓存命中、缓存失效、旧补丁升级和恢复清理测试。
7. 运行全部 Python、GUI 与隔离性能测试。
8. 使用隔离构建 PATH 重新运行 PyInstaller，校验资源、DLL、正式 EXE 启动与 SHA-256。
