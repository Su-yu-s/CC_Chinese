# CC_Chinese 全程管理员与免安装版设计

日期：2026-09-02  
状态：已批准  
决策：采用 EXE `requireAdministrator` 方案

## 背景

正式安装程序允许用户选择自定义目录，但当前提权代理只信任 `Program Files`。因此安装到 `E:\Code\CC\CC_Chinese` 的合法副本被错误判定为“不安全副本”。同一限制也使 `dist` 免安装版只能查看状态，无法完成核心汉化操作。

本设计覆盖并取代此前“普通权限启动、执行写操作时按需提权”以及“Claude Desktop 中文助手”这一产品名称决策。

## 目标

1. 产品名称、窗口标题、安装程序、快捷方式和关于页统一使用 `CC_Chinese`。
2. 安装版与 `dist` 免安装版双击后立即请求管理员权限。
3. 用户批准 UAC 后，程序全程在管理员权限下运行，不再启动第二个提权子进程。
4. 安装到自定义目录的正式版本和免安装版本均能汉化 WindowsApps 中的 Claude。
5. 保留版本兼容性门禁、完整快照、哈希校验、精确路径校验和可验证恢复等安全边界。

## 方案

### 启动权限

PyInstaller 构建参数和生成的 spec 都写入 `uac_admin=True`，最终 PE 清单必须包含 `requestedExecutionLevel level="requireAdministrator"`。用户取消 UAC 时程序不启动；用户批准后，GUI 与后台 Worker 均处于同一个管理员进程。

主界面执行汉化或恢复时直接调用事务安装器，并明确传入已经提升的权限状态。WindowsApps 操作不再经过依赖 EXE 安装路径的 `protected_distribution()` 提权代理，因此程序位于 Program Files、自定义安装目录或 `dist` 目录时行为一致。

旧的受限提权命令入口不再作为 GUI 的活动路径。若为兼容测试而暂时保留，其存在不得影响管理员主进程的直接执行。

### 快照目录

WindowsApps 的安全快照继续保存在 `%ProgramData%\Claude-zh-CN-official-backup\snapshots`。

管理员进程首次运行时：

- 若目录不存在，则创建目录、关闭继承，并仅授予 SYSTEM/Administrators 完全控制和 Users 读取执行权限；完成 ACL 复检后才允许写入快照。
- 若目录已经存在且 ACL 合格，则直接使用。
- 若目录已经存在但普通用户拥有写权限，则拒绝操作并报告稳定错误码，不读取或覆盖其中的快照，避免信任可能被提前篡改的基线。

安装程序仍可预先创建并加固该目录，但免安装版不再依赖安装程序完成初始化。

### 名称与分发

- 用户可见名称统一为 `CC_Chinese`。
- 内部可执行文件名、设置组织名继续使用 `CC_Chinese`。
- Inno Setup 继续要求管理员权限，并允许用户选择安装目录。
- `dist\CC_Chinese\CC_Chinese.exe` 是功能完整的免安装版本，不再描述为只能查看状态的副本。

### 安全取舍

始终管理员运行会增加 UAC 频率，也意味着位于用户可写目录的免安装 EXE 必须由用户自行确认来源。这是满足“免安装版双击即可汉化”的明确取舍。程序仍不扩大修改目标：只允许经过验证的 Claude WindowsApps 资源路径、配置键和受保护快照目录。

本次不包含代码签名、自动更新或遥测。

## 错误处理

- 非管理员进程进入核心写操作：返回权限错误，不尝试静默降级。
- UAC 被取消：Windows 不启动程序，不产生快照或修改 Claude。
- 快照目录创建或 ACL 加固失败：在首次文件写入前终止。
- 已存在的不安全快照目录：返回独立错误，不自动采用其中内容。
- 兼容性、备份和补丁后复检失败：继续使用现有事务回滚路径。

## 验证

1. 单元测试覆盖管理员直连分支、快照目录首次创建、合格 ACL 复用和不安全 ACL 拒绝。
2. 构建守卫检查产品名为 `CC_Chinese`，并检查 build/spec 均启用管理员清单。
3. 构建后读取 PE 清单，确认 `requireAdministrator`。
4. `dist` 免安装版与自定义目录安装版分别启动验证；两者不得再返回 `ELEVATION_UNAVAILABLE`。
5. 运行完整安全快照、失败回滚、精确恢复、翻译修复和 GUI 回归测试。
6. 重新编译 Inno Setup 安装包并记录 SHA256。

## 验收标准

- 双击任一发布版 EXE 立即出现 UAC；批准后窗口标题显示 `CC_Chinese`。
- 安装到 `E:\Code\CC\CC_Chinese` 的版本可以执行汉化与恢复。
- `dist\CC_Chinese\CC_Chinese.exe` 可以直接执行汉化与恢复。
- 首次使用免安装版时能安全初始化 ProgramData 快照根。
- 操作完成后的状态仍以真实文件复检结果为准。
- 当前 Claude 在测试期间不会因构建或自动化测试而被实际修改。
